# Лабораторная работа 2 — интеграционное тестирование системы функций

ИТМО, P3324, дисциплина «Тестирование программного обеспечения», вариант 98.
В паре с Козыревой Эмилией Владимировной.

Система функций: тригонометрические (sin, cos, csc), логарифмические
(ln, log2, log3, log5 — через общий LogBase) и составная SystemFunction поверх них.
Натуральный логарифм вынесен в отдельный REST-сервис (LnRestProvider/LnRestClient),
на его границе и проверялась интеграция.

**Что сделано:**
- Модульные тесты по каждой функции на JUnit5, с анализом эквивалентности при выборе тестовых случаев
- Контрактное тестирование REST-провайдера через Pact — consumer-тесты, provider-тесты и отдельная проверка breaking change
- UML-диаграмма классов — `docs/diag.uml`
- Экспорт результатов прогона в `output.csv`
- Покрытие — JaCoCo

**Запуск:**
```
mvn test
```
